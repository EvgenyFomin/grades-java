# 1. Введение

## О чём этот документ

Цель — разобраться, как операционная система Linux устроена в части **ввода/вывода (I/O)**: от загрузки ядра до асинхронных моделей, и как это отражается на программах на Java.

## Зачем это знать

- Приложения почти всегда ограничены не CPU, а вводом/выводом: диском, сетью, чтением файлов.
- Правильный выбор модели I/O (блокирующий / неблокирующий / асинхронный) определяет производительность и масштабируемость сервиса.
- Понимание слоёв ОС помогает читать `strace`, `dmesg`, `/proc` и понимать, что реально происходит «под капотом» у Java-кода.

## Структура

Документ последовательно раскрывает:

1. **Загрузку ОС** — путь от BIOS/UEFI до userspace (п. 2).
2. **Режимы работы процессора** — user mode и kernel mode, роль syscall'ов (п. 3).
3. **Систему привилегий** — права файлов, setuid/setgid, sticky bit (п. 4).
4. **Концепцию «Всё — файл»** — единый интерфейс к файлам, устройствам, процессам (п. 5).
5. **Файловые дескрипторы и стандартные потоки** (п. 6).
6. **Потоки в Java** и их связь с процессами/потоками ОС (п. 7).
7. **Переключение контекста** — как ОС планирует потоки и что сохраняется при переключении (п. 8).
8. **Модели синхронного, неблокирующего и асинхронного I/O** в Java и под капотом (п. 9).
9. **Специфику Linux**: pipes/FIFO, виртуальные ФС, inode и ссылки, systemd (п. 10–13).

Каждый раздел сопровождается практическими скриптами и примерами кода.

## Основные понятия

| Понятие | Кратко |
| --- | --- |
| syscall | Системный вызов — мост из user mode в kernel mode |
| fd (файловый дескриптор) | Числовой хэндл к открытому файлу/сокету/устройству |
| Virtual File System (VFS) | Слой абстракции, делающий всё «файлами» |
| Виртуальные ФС | `/proc`, `/sys`, `/dev` — интерфейс к данным ядра |
| Поток ОС (LWP) | Единица планирования ядра; Java-поток = LWP |
| epoll / io_uring | Механизмы ядра для мультиплексирования и async I/O |

## Инструменты, которые понадобятся

- `strace` — трассировка системных вызовов.
- `dmesg` — журнал ядра.
- `systemd-analyze`, `systemctl` — анализ загрузки и сервисов.
- `stat`, `ls`, `mkfifo` — работа с файлами и типами.
- `jstack`, `jcmd` — диагностика Java-процессов.
